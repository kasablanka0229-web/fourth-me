FOURTH ME V14 START — Galaxy PWA
1. ZIP 압축을 풉니다.
2. index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png 파일을 모두 동일한 HTTPS 웹사이트 폴더에 업로드합니다.
3. Galaxy Chrome에서 업로드된 https:// 주소로 접속합니다.
4. Chrome 메뉴(⋮) > 홈 화면에 추가 > 설치(표시는 기기마다 다를 수 있음).
5. 앱에서 행동 한 줄 입력 > 등록하고 바로 시작.
6. 보관함에서 JSON 백업을 주기적으로 내려받으세요.

중요: 로컬 HTML 파일(file://)을 열면 홈 화면 설치 및 오프라인 PWA 기능이 동작하지 않을 수 있습니다.
V12/V13 기록은 자동 이전되지 않습니다. V13 가져오기는 같은 origin에 기존 데이터가 있을 때만 작동합니다.
기록은 브라우저 로컬 저장소에 보관되며 자동 동기화/암호화/클라우드 백업은 제공하지 않습니다.
