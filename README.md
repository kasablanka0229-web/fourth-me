- 삶의 흐름 상단에 목표·시간·감정 3대 시스템의 읽기 전용 요약 추가
- 목표: 기존 인생 영화 및 완료 행동
- 시간: 기존 타이머 세션에 기록된 시간
- 감정: 기존 아침·밤 기록 및 원하는 감정
- 입력 폼, 카테고리, 탭은 늘리지 않음
