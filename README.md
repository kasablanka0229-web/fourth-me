# FOURTH ME V12 · MY LIFE, IN MOTION

**목표:** 오늘의 작은 선택을 기록하면서, 미래의 내가 시간의 흐름 속에서 삶의 의도·감정·행동·전환점을 되돌아볼 수 있는 평생 기록 시스템.

## 설치 (GitHub Pages)

1. **먼저 기존 V11에서 전체 JSON 백업을 다운로드하세요.** V11의 `삶의 흐름`에는 별도 JSON 백업이 있으므로, 해당 파일도 함께 보관하면 더 안전합니다.
2. ZIP 안의 `index.html`, `legacy.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`를 **같은 GitHub Pages 경로**에 업로드하세요. 기존 파일을 교체하되, 기존 GitHub Pages 사이트 주소를 유지해야 브라우저 로컬 기록을 계속 사용할 수 있습니다.
3. **개인 기록이 담긴 JSON 백업 파일은 공개 저장소에 업로드하지 마세요.** 앱 코드만 배포하세요.
4. 웹사이트를 새로고침하고 `FOURTH ME V12`가 표시되는지 확인합니다. 이전 화면이 보이면 브라우저 새로고침 및 사이트의 서비스 워커 업데이트를 확인하세요.
5. `보관함 → 전체 JSON 백업 다운로드`를 눌러 V12 통합 백업을 하나 저장하세요.

> `index.html`은 CSS/JavaScript가 내장된 단일 HTML 파일이지만, 설치형 PWA와 원본 V11 화면을 사용하려면 나머지 파일도 함께 업로드해야 합니다.

## 화면 구성

- **오늘:** 자유로운 할 일 추가·완료, 2분 타이머, 일시정지/재개/10분 연장, 선택적 아침·밤 인생 영화 루틴.
- **나의 영화:** 삶의 이야기·메시지·원하는 감정·음악·환경 기록. 저장할 때마다 새 버전을 생성하여 과거 방향 보존.
- **삶의 흐름:** 연도별 실행 추이, 의도→감정→행동→시간 연결, 전환점과 과거 기록을 포함한 타임라인, 선택적 월간 회고.
- **보관함:** 모든 `fourth-me-*` 로컬 저장 키의 원문 통합 백업, JSON 복원 미리보기, 이전 V11 화면 열기.

## 이전 버전과의 관계

- 기존 V2 행동 데이터(`fourth-me-v2-data`)를 **계속 사용**합니다. 새로운 행동도 같은 데이터에 추가됩니다.
- V6 삶의 설계, V10 방향, V11 삶의 흐름에 저장된 삶의 의도를 **출처를 붙여 V12 영화 버전으로 가져옵니다**. 기존 키를 삭제하거나 덮어쓰지 않습니다.
- 기존 V6/V11 전환점, V2 하루 기록, V9 타이머 기록은 `삶의 흐름`에서 읽어 표시합니다.
- 기존 마인드맵·일정·정체성 노드 등은 `legacy.html`에서 계속 열 수 있습니다. 두 화면은 동일한 웹사이트 주소에서 로컬 저장소를 공유합니다.
- **주의:** V11에 있던 모든 입력 필드가 V12 첫 화면으로 옮겨진 것은 아닙니다. 복잡한 기존 화면은 의도적으로 보관함의 고급 화면으로 분리했습니다.

## 데이터 보존과 제한

- 로그인, 자동 클라우드 백업, 기기 간 동기화, 데이터 암호화는 없습니다. **로컬 저장소는 기기/브라우저/사이트 주소에 종속됩니다.** 정기적으로 JSON 파일을 안전한 장소에 보관하세요.
- `V12 전체 백업`은 현재 같은 사이트에 저장된 `fourth-me-*` 키를 원문 그대로 포함합니다. 복원은 **동일 키를 교체하고 그 외 키는 유지**합니다. 복원 전 반드시 현재 상태를 별도 백업하세요.
- 구버전 JSON 복원 지원 범위: V1/V2/V3의 `FOURTH ME` 형식, V6 통합 형식, V9 통합 형식, V11 `fourth-me-v11-story` 형식, V8 시작 기록 확장 형식. 모든 임의의 구버전 변형 형식을 자동으로 해석할 수 있는 것은 아닙니다.
- V11에서 실행 중이던 타이머는 V12에서 자동 재개하지 않습니다. 이전 V9 타이머 원문과 완료 기록은 보존됩니다.
- 타이머 시간은 기기 시계의 경과시간을 기반으로 계산합니다. 앱을 벗어나도 경과시간은 이어질 수 있으나 **실제로 집중했는지를 감지하거나 검증하지 않습니다.** 타이머 종료와 할 일 완료는 분리되어 있습니다.
- 영화·감정 상상은 동기·자기성찰 도구이지, 외부 현실을 자동으로 바꾸는 기술이나 임상적 치료법이 아닙니다.

## 빠른 점검

1. 오늘 할 일 추가 → 체크 완료 → `삶의 흐름`의 완료 행동 집계 확인.
2. `나의 영화`에서 이야기·감정 저장 → 같은 화면에서 변경 이력 확인.
3. 아침 루틴에 행동 입력 → `오늘의 작은 행동`에 한 번만 추가되는지 확인.
4. 타이머 시작·일시정지·재개·종료 → `삶의 흐름`에서 시간 기록 확인.
5. `보관함`에서 전체 JSON 다운로드 → 다운로드 폴더에 파일이 생성됐는지 확인.

연구·설계 판단은 `RESEARCH.md`, 검증 결과와 한계는 `QA_REPORT.md`에 정리했습니다.
